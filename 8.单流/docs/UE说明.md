# UPA单流UE链路说明

当前入口已适配UPA，POS使用连续HAQSE频率定位并只量化一次三维坐标；没有新增极化或双流。

## 计算过程

1. UE生成空间消息，再按CPU相同的解码规则得到最终UPA空间波束。POS的36 bit坐标分配固定为13/14/9，HAQSE频率量化与POS定位分开。
2. UE对参与AP的联合观测信道求主右奇异向量，按AP分块投影到空间波束，得到AP相位。
3. 固定首AP全局相位，其余相位用4 bit圆周量化。CPU使用空间消息和这些相位恢复单列发送向量。没有幅度反馈，也没有双极化2×Ns系数矩阵。
4. 总功率1，每AP功率1/B。400 MHz仅用于窄带频谱效率换算。

## 默认反馈

UPA32×32、B=8时，HAQSE/DFT/POS的UE总量为112/70/64 bit；相比CPU分支分别增加28 bit AP间相位。Type-I/II空间码本适配为二维，其本地选波束和贪婪AP相位规则暂保留，默认总量140/292 bit。Docomo结构适配的本地码本改为UPA二维DFT，AP逻辑DFT与三轮更新保留，默认129 bit；其beta为2 bit QPSK，不等同于一般链路4 bit相位。

目前尚未增加同一算法的完美CSI配对，也未恢复原基线定义。这些后续项不包含在本次UPA与POS修复中。当前小样本结果只验证处理链路、功率和反馈口径，不作算法排名。
