# 单流UE链路实现说明

本文件说明当前代码的UE链路，不是新增UPA性能报告。已有实现和结果采用单极化单流ULA，UPA尚未适配。

## 计算过程

1. UE生成与CPU链路相同的量化频率、DFT索引或坐标消息，并按相同规则生成最终空间波束。
2. UE对全部B个参与AP的联合观测信道Hobs求主右奇异向量，再按每AP分块投影到空间波束，得到各AP的复投影系数。
3. 只保留相对首AP的相位，按4 bit的16个圆周相位量化。当前单流程序不量化AP系数幅度，所有AP的发送幅度仍为1/√B。
4. CPU利用空间消息和B−1个相对相位，组装单列预编码w，发送同一个数据流。观测CSI用于UE计算，不是作为完整CSI矩阵上传。
5. 速率为400×log2(1+rho_data×‖Hw‖²)，单位Mbps。400 MHz仅是带宽乘数；当前信道为窄带模型，不含接收信道估计误差、反馈时延或导频及反馈资源扣除。

关键实现位于 [run_single_stream_task2.m](../run_single_stream_task2.m) 的paired_design、co_phases、design和evaluate_design。这套向量预编码不使用历史双极化程序的2×Ns矩阵系数或108/216 bit幅相反馈格式。

## 各方法变化与开销

几何方法在空间消息之外增加4(B−1) bit相位。B=8、N=64时，HAQSE为70 bit、DFT为55 bit、POS为52 bit。该开销不是双极化报告中的252 bit。

Type-I为每AP选择一个过采样DFT波束，再以观测有效信道贪婪选择AP间相位；Type-II先复合每AP两个空间波束，内部幅度3 bit、相位2 bit，再做AP间相位对齐。两者AP间相位仍为4 bit，因此B=8、N=64时分别为100/212 bit。二者选波束和相位规则与几何方法不同，速率不保证形成上下包含关系。

Docomo适配使用4倍本地DFT、2 bit QPSK beta、AP逻辑栅格DFT以及三轮交替更新；B=5至10时使用beta坐标更新代替全枚举。B=8、N=64时为81 bit。它使用完整UE观测信息选码；不是CPU仅凭参考AP几何反馈的方案，也不声称与原论文完整实现等价。

真实信道SVD直接取主右奇异向量，总功率为1，放松每AP等功率和有限码本约束。它是当前单流信道的理想参考，不是可实施的有限反馈方法。

## 仿真结果的归属

UE输出含7种方法，19个设置标签、400位置，共53,200条记录。HAQSE/DFT/POS的空间定位来自同一套消息，因此CPU和UE的定位误差数据相同；差异主要在AP间相位来源。图及数据索引见 [single_stream_full](../results/single_stream_full/README.md)。

既有位置方法从量化HAQSE频率定位，而非原连续HAQSE定位流程；24 bit坐标的分配同步也尚未独立验证。当前结果不能直接替代原第6目录结果，更不能解释为UPA验证，具体边界见 [整理说明](整理说明.md)。
