# UPA单极化UE计算说明

主实验使用带噪观测CSI。Type-I从联合主模式分块选DFT波束；Type-II在正交分组内选两条，组合幅度3 bit、内部相位2 bit。HAQSE/DFT/POS由自身整数消息恢复空间波束，POS从连续频率定位后只量化坐标。

普通五种方法对波束和联合主模式分块做投影，去除首AP相位后量化为4 bit。Docomo结构适配使用论文对应的QPSK beta与AP逻辑DFT模式，属于独立算法结构；论文Type-I NCJT不同于当前项目含共相位基线。

双流保留第一波束与相位，将总功率平分给两流，第二流只反馈其余AP各4 bit相位，B=8时增加28 bit。默认Type-I/II、Docomo、HAQSE、DFT、POS的单双流有效载荷分别为140/168、292/320、129/157、112/140、70/98、64/92 bit。CPU从完整比特串重建两列预编码，不使用UE浮点系数。

400位置单流正式扫描及400位置双流完整扫描均已完成。双流覆盖LOS和MIX及观测SNR、UPA规模、AP数、K因子；增量在同一位置同一参数的单双流配对内计算，保留负收益。使用每流MMSE SINR求和并同时记录联合速率，不将两列功率相加套用单流公式。

详细结果见[单流报告](UPA单流400位置正式实验报告.md)和[双流完整报告](UPA单极化双流400位置完整实验报告.md)。前期[32位置最小验证](UPA单极化双流扩展验证报告.md)保留为阶段记录。同算法完美CSI仅留作V2小样本诊断；主参考始终为真实无估计噪声信道的SVD。完美CSI不等于数据噪声消失。
