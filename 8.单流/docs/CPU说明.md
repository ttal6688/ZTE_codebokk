# UPA单极化CPU计算说明

当前已完成400位置单流和32位置双流验证，详细数据分别见[单流报告](UPA单流400位置正式实验报告.md)与[双流报告](UPA单极化双流扩展验证报告.md)。

UE从三个参考AP的带噪观测生成HAQSE频率、DFT索引或POS坐标整数消息。POS使用连续频率定位后只量化一次坐标，固定13/14/9 bit。CPU仅接收这些空间有效载荷与公共配置，不接收参考AP观测信道、真实信道或UE连续位置。

CPU解码位置和各AP空间波束，用公开几何构造模型，求联合主模式并投影得到第一相位。双流仍复用相同波束与第一相位，利用模型有效信道设计第二相位，不增加UE反馈。默认HAQSE/DFT/POS无论一流或两流均84/42/36 bit。

固定的是参考消息规模，不是模型4×BN、输出B组权重或整体计算量。第二流搜索增加CPU工作量，当前不声称复杂度不变，也不把R当作导频符号数。真实信道只在评价时使用。

CPU单流图中的Type-I/II是UE共享参考，双流最小CPU组只含三种几何方法及SVD参考。SVD单流为总功率约束最优上界，双流为等功率参考。400 MHz直接换算。定位误差、坐标截断和越界分别记录。
