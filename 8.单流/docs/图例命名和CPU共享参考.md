# 图例命名和CPU共享参考

2026年10月24日按用户要求统一最新单流与双流报告及图表名称。

| 内部方法 | UE图例 | CPU图例 |
|---|---|---|
| TYPE_I | 全反馈Type-I(UE) | 全反馈Type-I(UE) |
| TYPE_II | 全反馈Type-II(UE) | 全反馈Type-II(UE) |
| HAQSE_R3 | 空间频率 | 空间频率 |
| DOCOMO_NFLOS | Docomo | Docomo(UE) |

图例中的空间频率沿用原HAQSE估计器和整数频率反馈。名称调整不改变算法、反馈字段或仿真数据。“全反馈”是按用户约定采用的Type-I/II名称，实际反馈仍为本项目定义的码本索引、组合系数和共相位字段，不代表逐元素上传原始CSI。

CPU图中的Docomo(UE)复用同一位置、参数、信道下的UE结果。单流包含吞吐量、频谱效率和反馈量；双流包含吞吐量、单双流增量、第二模式功率比、默认配置柱状图、增量CDF及反馈量。Docomo不输出位置估计，定位误差图不添加该方法。

这项参考不作为新增CPU几何算法，不新增仿真样本，不改变原始记录数及双流正负收益统计。原始CSV和gzip、冻结输入以及算法实现均保留；只是从UE结果选出对应记录用于CPU图表和报告。CPU参考的数据来源另存各正式结果目录中的CPU_Docomo_UE_reference_summary.csv。

图例统一为Docomo，正文继续说明当前UPA单极化、逻辑AP DFT及统一双流扩展的实现范围，不将其误称为论文所有设置的完整复现。
