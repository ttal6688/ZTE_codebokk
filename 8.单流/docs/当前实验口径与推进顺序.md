## 已确定的口径

单流与后续双流均使用UPA、单极化、同一冻结部署和400个位置。CPU与UE分开计算、汇总和绘图。主参考是完美CSI下直接SVD的最优单流预编码；普通算法用带噪观测CSI，真实信道仅供评价。额外同算法CSI配对只保留为小样本诊断，不扩为正式主扫描。

位置反馈先用连续HAQSE频率定位，再量化一次坐标，固定13/14/9 bit。普通UE方法用联合主模式投影和4 bit相对相位；CPU仅凭空间消息与公共几何模型计算相位。所有发送向量由实际整数消息解码生成。总发送功率1、每AP总功率1/B，SVD放松每AP等功率约束。

400 MHz直接将频谱效率换算为Mbps，系数400。无需新增OFDM模型。固定的是参考消息数量与维数，不宣称整个CPU复杂度固定。

上述CPU/UE相位规则在第5、第6目录已建立，本轮对第8目录的修正是恢复一致性和补齐完整消息重放，不将这些原则描述为首次提出。

## Docomo来源与适配

来源为用户提供的Xiang Li、Xiaolin Hou、Lan Chen的Near-Field Line-of-Sight MIMO Precoding with Distributed Antennas，IEEE PIMRC 2024。第IV节式25至27给出每AP本地波束、量化共相位、AP二维DFT模式与交替优化思路；第V节采用QPSK共相位。当前代码采用相同分块结构，但不规则AP用一维逻辑DFT模式，固定单极化单流、本项目本地码本与信道。三轮坐标更新属于实现选择，并非论文指定，不归因于不存在的原始代码。

论文Type-I参考为NCJT，当前项目Type-I含共相位，图例与报告明确区分。论文表II的26 bit不可套用；本项目默认B=8、32×32时实际129 bit。名称保留Docomo结构适配，不声称论文完整复现。

## 按顺序执行

1. 同步本口径与论文对应关系。
2. 验证Docomo交替更新不降低观测目标，解码与直接计算一致，小规模固定波束枚举检查坐标更新与最优值之差，记录结果而不承诺全局最优。
3. 上述检查通过后，运行400位置单流主扫描。只运行观测CSI方法和真实SVD参考；原小样本CSI配对留作补充。19个曲线标签中的重复默认配置可以缓存复用，不将重复标签当成独立样本。
4. 再做单极化双流最小验证，预定32个位置，LOS和K=10 dB混合信道，默认32×32、B=8、观测30 dB。第二流复用每AP的空间波束，只增加跨AP相位。各方法都验证，CPU三种几何方法与UE六种方法分开。记录第二模式、每流MMSE SINR、联合速率、相对单流收益及负收益比例，不自动升级为完整双流扫描。
